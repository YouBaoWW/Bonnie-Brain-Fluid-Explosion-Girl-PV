# 总提示词（整理模板）

制作一部约191.58秒、1920×1080、60fps的黑白纸面同人PV，主角以邦妮为主，芬妮作短暂对置。以原速音频和绝对LRC句时码为轴；自行提供有权使用的音频、歌词、角色图，公开代码内不要带这些媒体。

视觉使用调查案卷、手机、放大镜、证据网、泼墨、轨道与太阳系。非高潮人物以纯黑剪影为主，保留粉色领带及黑色五瓣花；高潮可使用完成立绘。人物完整等比，短信场景的两条腿和两只鞋必须自然完整，在画面内且不被字幕/墨池遮住。

每句先确定完整主句的可读停顿，再设计关键词、镜头和退出。保留一次人物入场，不跨pose重启；背景持续有层次运动。主词条半透明，字按真实背景黑白反差选择。快速推拉/翻转可短时方向模糊和拖影，停稳时清楚。

神经线路、翻转手影、手机铰链、同镜头推拉旋转错位假名以及文件间移动视角各有明确空间关系。不要靠单调切换或空白等待。结尾太阳系两个人左右分置，附文件/手机/放大镜，随后保持最终纸面主题。

所有状态由renderFrame(t)决定，乱序seek必须相同。先做native关键帧与动态板，再编码整片并从实际MP4抽帧，分清原生、捕获、编码证据。不要把全歌词/素材权利当作源码MIT的一部分。
