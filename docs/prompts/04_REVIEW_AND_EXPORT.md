# 验收与迭代（整理模板）

先输出静态/运动/退出三态及边界帧，再实际浏览器预览。检查主句完整、字幕不遮挡、人物足部在有效画面内、黑花细节、颜色与多次seek确定性。对双腿使用原图下腿/靴子ROI按真实变换投影并核实际像素，不能把裙摆当成第二条腿。

正式导出以原始RGBA+ACK背压送编码器，绝对t逐帧；分段保存checkpoint并检查source/settings哈希，改源码必须重新开输出目录。原音频只编码一次，比较片复制音轨，严格全AV解码，PTS应等frame/fps。先完成实际编码抽帧，再确认成片，不把native证据当作encoded证据。

本包仅提供关键帧工具与传输helper，私有生产审计器和媒体未公开。需要自己实现成片管线时应按上述方法做真实验证，不放宽缺素材、字幕、帧数或音频检查来凑通过。
