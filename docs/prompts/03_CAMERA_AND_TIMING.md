# 镜头与节奏（整理模板）

只用绝对歌曲时间，不用累计动画时钟控制导出。分开设计50ms左右入场、短促运动、足够停读和快速退场；给短镜头安排一个主动作。视角推拉需有空间参照，纸面纹理、规则线和证据微字保持同一世界坐标。

表情包保持原128px彩色单张/三连序列，切换依据实际音频kick/snare起音分析再对齐CFR60，而非盲目等距。记录检测窗口、hop、频段、onset、切点和误差；不得声称没有做过的人工听校。最终逐字速度用句时码、字数估计和数字帧表描述限制。

文件涂黑随同一纸面单应变换，完整覆盖字段；聊天用斜侧纵深相机。年份句退场后用近景推进和回拉进入下段全身，不能预先显示下一句。柜子每次十四文件飞出翻转，局部动态模糊，主句在文件之后绘制以保阅读。
