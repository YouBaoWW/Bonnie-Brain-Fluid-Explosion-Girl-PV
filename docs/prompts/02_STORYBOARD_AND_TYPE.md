# 分镜与文字（整理模板）

先按句时码布置主句，确保前段及时出现并完整停读。文字背景不得用整块不透明矩形盖掉动态背景；真实纸张、短信屏和实体案卷可以有纸面。图标行的横线位于图标上方，文字在线上方，图标不可重复，可加入不同社交软件图标。

第一次副歌使用关键词爆字，第二次以头内积字、冲向中心、碎裂成证据网加大规模。两次人物只入场一次，年份快速增长后虚化退后，人物突出。单人短信与双人短信的气泡不要覆盖双腿。

假名采用同一场景中的粗前景与细后景：快速推拉、旋转、错位叠字；镜头移动连续，读词停稳，不能出现中间突兀手机条或长空白。最后在同一张文件内移动，再移到下一文件，避免每几帧不断换纸。
