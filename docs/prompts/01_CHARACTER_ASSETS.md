# 角色与道具（整理模板）

基于自有或有权使用的角色参考生成透明PNG。保持身份、衣帽轮廓、服装比例；全头全脚、手指清楚、边缘留6%左右余量。普通镜头转纯黑剪影，只保留粉色领带，黑色五瓣花清楚。高潮立绘保持原单色线稿，避免额外服装重设计。

手机剪影必须有两段翻盖轮廓和屏幕负形。出现少腿时先查看原PNG和实际构图变换，确认是否底部裁切；原图有双腿就只改构图，不用代码伪造人体。真正缺失才做窄范围图像编辑。

道具可用独立ImageGen透明素材：麻绳保留扭绞纤维；枕头完整边缘；马卡龙按原堆叠层次再转纯黑。方糖从顶部落到底部出画，不加落水和杯口淡出。帽子悬停小旋转，不飞出；角色只保留粉领带，钢梁细节保留。
