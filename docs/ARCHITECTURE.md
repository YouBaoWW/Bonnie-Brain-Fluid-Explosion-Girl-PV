# 实现结构

src/renderer/full-v11.js 负责画布、外部素材表、文字绘制、字体选择与状态输出；cinematic-v11.js 负责完整时间轴和场景派发；perspective-v02.js 负责透视文字平面，timing.js 采样节奏特征。early/late、documents、characters、spatial 与 fixes 模块保留最终 V11 的局部修正。

渲染入口是 renderFrame(t)，时间使用绝对歌曲秒数；不依赖上一帧积累。角色保持等比，黑剪影保留领带色，短信气泡避开双腿。主句在真实纸/手机上绘制，模糊只服务短时运动，停稳阅读时清晰。年份后近景通过推近、倾斜、回拉衔接下一全身镜头。包内演示图是几何占位，因此人物位置可研究，不能评价实际角色美术。

data/release-source-map.json 记录生产源码哈希及公开副本位置。公开副本有路径、演示文字、可选字体和占位适配，不能宣称与生产成片字节相同。data 下保留 cue ID、时码、表情切点和逐字 CFR 帧坐标，删除原音、完整歌词及可重建声波的测量特征。合成节奏只供演示。
