# 本地发布检查

本仓库仅发布源码、提示词、说明和封面。参考仓库仅作目录和说明风格参考。发布内容已通过文件白名单、逐项哈希、ZIP CRC、解压比对和无原素材演示检查。

运行 npm test，检查所有 JS语法和相对导入；npm run doctor；启动无网络的 demo 并按多个乱序时点截图。仅允许 docs/images/cover.png 这一图片。拒绝音视频、字体二进制、docx、原始歌词、其他图片、缓存、node_modules、outputs、秘密凭据、会话ID和个人绝对路径。

确认 release manifest 的每项SHA与实际文件一致，解压后再次检查路径穿越/重复路径/CRC，禁止将生产根目录直接压缩。提示词历史仅保留真实prompt与必要版本/调用状态，机器源路径、图像会话UUID及参考截图已移除。
